## 🔴 严重（部署前必须处理）

### O1 · 跨主机从未实测
* **性质**：**空白**，不是缺陷。
* **已做**：修复了致命前提（对外 locator 曾硬编码 `127.0.0.1`）；
  给出配置要求（组播、防火墙端口、多网卡 `advertised_address`）。
* **为什么仍算严重**：部署形态几乎一定是多机，而这一点**没有实测证据**。
* **本轮实测的坏消息**：`ip netns` / `veth` / `tc netem` 在本环境**全部不可用**
  （WSL 权限受限），无法用网络命名空间模拟两台主机。
  同机也无法严格验证 locator 语义（因为 socket 绑 `INADDR_ANY`，所有本地地址都可达）。
* **结论**：**必须有第二台主机才能验证**，我不做"看起来像验证"的实验。

### O2 · 回放方向高速不可靠
* **性质**：**确证的限制**（有 `RcvbufErrors` 证据）。
* **根因**：接收端**内核接收缓冲**溢出，不由 Stratum 单方面决定。
* **Stratum 侧可做**：发送限速（已实现，**默认关闭** —— 它并未消除丢包，
  却把吞吐从 ≈8 万压到 ≈2 万条/秒）。
* **建议**：接收端调大 `SO_RCVBUF` / `net.core.rmem_max`。
  本机 `rmem_max = 212992` 且 `sysctl -w` **权限被拒**。

## 🟡 中等（能力缺口 / 未验证）

| # | 问题 | 说明 |
|---|---|---|
| O4 | **单条样本 > 64 KiB 不支持** | 未实现 `DATA_FRAG`；仅保证**显式失败**（不发坏包）。**已决策：暂不实现**（成本≈当初实现可靠传输；收益仅覆盖该场景），见 `design/16` D2 |
| O5 | **IPv6 完全未支持** | 实测：`AF_INET` 出现 21 次，`AF_INET6`/`in6_addr`/`sockaddr_in6` **一个都没有** —— 双栈整体缺失。**已决策：暂不实现**，改造清单见 `design/16` D3 |
| O6 | **多网卡地址选择未实测** | 自动探测 + `advertised_address` 覆盖**已就绪**；但同机 socket 绑 `INADDR_ANY` 使所有本地地址可达，**单机无法区分对端发往哪个地址** → 与 O1 合并跟踪 |
| O7 | **`DetectLocalAddress()` 在隔离网络会退化** | 依赖 `connect("1.1.1.1")` 选出口地址；无外网路由时回退 `127.0.0.1` |
| O8 | **首条数据靠"新 SN 重发"补救** | VOLATILE 边界**未根治**：回放恒多出最多 1 条重复内容 |
| O9 | **"哪些数据真的到了"不精确** | `acked` 依赖对端 ACKNACK 的及时性 —— 这正是发送窗口方案失效的原因 |
| O10 | **`HandleAcknack` 的位图解析路径未用真实位图验证** | 只验证了 `base_sn` 路径；大端位序按规范实现，**无实测证据** |
| O11 | **`pending_` 裁剪粗暴** | 超过 4096 条删最早 1024 条 → 长回放时老样本无法重传 |

## ⚙️ 环境约束（影响结论适用范围）

* 上游 `/UserData/Fast-DDS` **只读**（约束，非问题）；
* WSL **单机单域**，`netns`/`veth`/`tc` 不可用，`rmem_max` 不可调（权限）；
* 组播加入失败告警 + `7400/7438/7439` 存在 WSL 之外的绑定者 → 干扰 domain 0 的偶发失败；
* WSL 里 `wsl bash -lc '...'` 经 PowerShell 传参时 `$VAR`/`$(...)` 会被吞 →
  所有多步命令一律**写成脚本文件再执行**。

## 处理优先级建议

1. **O3 版本控制**（用户可立刻做，收益最大）；
2. **O1 跨主机实测**（需第二台主机）；
3. **O4 `DATA_FRAG`**（若确有 >64 KiB 样本需求）；
4. **O2 的部署说明**（把接收端缓冲配置写进部署文档）；
5. 其余按需。
